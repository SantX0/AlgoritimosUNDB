# UPDS
#UpSpot
O UpSpot é um uploader de musicas feito para artistas independentes ou para 
você lançar aquela musica engraçada que você fez com o seu amigo em uma
madruga de sexta-feira dentro do aplicativo do spotify.

#Funções:

#Cadastro
Cadastrar musicas através da opção de cadastro para adicionar seu musica e quando vai ser lançadas.

#Buscar
Aonde você pode buscar as musicas cadastradas.

#Atulizar
Atualizar as informações de uma musica, seja alterar a data de lançamento até mesmo o nome 
dos autores, co-autores e produtores.

#Apagar
Aonde você exclui alguma musica que você tem vergonha de lançar ou achou muito
ruim.
